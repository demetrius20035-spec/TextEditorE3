# Mini-IDE (Текстовый редактор)

Минимальная IDE на Delphi (VCL, Win32), собирается под **Delphi XE8 / RAD Studio 16.0**.
Редактор на базе `TRichEdit` с нумерацией строк, подсветкой синтаксиса по расширению
файла, выбором кодировки и запуском внешнего интерпретатора (например, Python) с
перехватом вывода в консоль.

## Возможности

- Открытие/сохранение `.rtf` (с форматированием) и любых текстовых файлов
  (`.txt`, `.py`, `.pas`, …) как обычного текста.
- **Нумерация строк** — отдельный «жёлоб» (gutter) слева, номера всегда совпадают
  со строками (см. ниже «Как устроен нумератор»).
- Подсветка синтаксиса по правилам из `syntax_highlight.ini` (Python, Pascal, JS,
  C/C++, SQL, HTML, CSS и др.).
- **Поиск и замена** (в т.ч. «Заменить всё»), **переход к строке**.
- **Комментирование/раскомментирование** выделенных строк (префикс берётся из
  правил подсветки текущего языка).
- **Авто-отступ**: новая строка наследует отступ предыдущей.
- **Масштаб** (Ctrl+колесо / меню «Вид») и переключатель **переноса строк**.
- **Список последних файлов** в меню «Файл», **открытие перетаскиванием** (drag&drop).
- Выбор кодировки чтения/сохранения текста: **UTF8** (по умолчанию), **CP1251**, **CP866**.
- **Запуск** (F5) по настройкам из `run_settings.ini`, в т.ч. запуск открытого файла
  по его расширению; **остановка** процесса (Ctrl+F2) и вывод кода возврата;
  stdout/stderr выводятся в нижнюю панель в реальном времени.
- Заголовок окна показывает имя файла и метку несохранённых изменений (`*`).
- Панель состояния с путём к файлу и позицией курсора (`Ln`, `Col`).
- Базовое форматирование текста (шрифт, размер, цвет, Ж/К/Ч, выравнивание).

## Горячие клавиши

| Клавиши | Действие |
|---------|----------|
| Ctrl+N / Ctrl+O / Ctrl+S | Новый / Открыть / Сохранить |
| Ctrl+Shift+S | Сохранить как |
| Ctrl+F / Ctrl+H | Найти / Заменить |
| Ctrl+G | Перейти к строке |
| Ctrl+/ | Комментировать строки |
| Ctrl++ / Ctrl+− / Ctrl+0 | Масштаб: больше / меньше / сброс |
| Ctrl+колесо | Масштаб |
| F5 / Ctrl+F2 | Выполнить / Остановить |
| Ctrl+Z / Ctrl+Y | Отменить / Повторить (штатно в RichEdit) |
| F1 | Шпаргалка (возможности и горячие клавиши) |

Те же сведения доступны прямо в программе: меню **Справка → Шпаргалка** (или F1).

## Сборка

### Из IDE
1. Открыть `Project1.dproj` в RAD Studio (XE8).
2. Выбрать конфигурацию `Release` (или `Debug`) и платформу `Win32`.
3. **Build** (Shift+F9).

### Из командной строки
```bat
build.bat            :: Release
build.bat Debug      :: Debug
```
`build.bat` вызывает `rsvars.bat` из установки RAD Studio и запускает MSBuild по
`Project1.dproj`. Если RAD Studio установлена не по стандартному пути — поправьте
переменную `RSVARS` в начале `build.bat`.

## Запуск скрипта (Run-конфигурация)

Кнопка запуска сохраняет текущий текст редактора в файл из `run_settings.ini`
(кодировка UTF-8) и выполняет указанный интерпретатор. Настройки правятся в меню
**Настройки → run_settings.ini** или прямо в файле:

```ini
[Run]
Executable=python
FileName=source.py
Arguments=10 20
```

- `Executable` — команда/путь интерпретатора (например, `python`).
- `FileName` — имя файла, в который сохраняется код перед запуском.
- `Arguments` — аргументы командной строки.

## Кодировки

По умолчанию редактор работает в **UTF-8** — это правильный выбор для исходного
кода и Python 3. Чтобы открыть старый файл в **CP1251**/**CP866**, выберите нужную
кодировку в выпадающем списке на панели инструментов — файл будет перечитан.

## Как устроен нумератор строк

Номера рисует лёгкая панель `TPaintBox` (`FGutter`). На каждой перерисовке для
каждой видимой строки запрашивается её реальная экранная координата Y через
`EM_POSFROMCHAR`, и номер рисуется ровно напротив строки. Благодаря этому номера
всегда совпадают со строками независимо от прокрутки, размера шрифта и высоты строк.

Перерисовка инициируется при прокрутке (`WM_VSCROLL`, `WM_MOUSEWHEEL`), изменении
размера (`WM_SIZE`), изменении текста и навигации курсором. Никаких таймеров и
подгонки позиции прокрутки — в отличие от прежней реализации (см. `AUDIT.md`).

Ключевой момент: чтобы номера совпадали со строками точно, перенос строк должен быть
**выключен** (тогда экранная строка = логической). Одного `WordWrap := False` для
`TRichEdit` недостаточно — движок продолжает заворачивать текст по ширине окна, из-за
чего гаттер нумерует перенесённые куски и «убегает» вперёд. Перенос реально
отключается сообщением `EM_SETTARGETDEVICE(handle, 0, 1)` — это и сделано.
Номера строк при желании отключаются в меню **Вид → Номера строк**.

## Структура проекта

| Файл | Назначение |
|------|------------|
| `Project1.dpr` | Точка входа |
| `Unit1.pas` / `.dfm` | Главное окно: редактор, нумератор, подсветка, запуск |
| `Unit2.pas` / `.dfm` | Диалог настроек запуска (Run-конфигурация) |
| `Project1.dproj` | Проект сборки XE8 (Win32, Debug/Release) |
| `Project1.res` | Ресурсы (иконка, версия, манифест) |
| `syntax_highlight.ini` | Правила подсветки синтаксиса |
| `run_settings.ini` | Настройки запуска скрипта |

## Кодировка исходников

Файлы `.pas`/`.dpr` хранятся в **UTF-8 с BOM**, чтобы Delphi XE8 корректно читал
русские строковые литералы и комментарии независимо от системной локали.
